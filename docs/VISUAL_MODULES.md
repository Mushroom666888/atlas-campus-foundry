# 可视化模块体系

内置模块共 94 个。模块数量指可安装的能力契约，不代表 94 套独立后端，也不包含用户发布的扩展模块。商业和社区能力详见 [商业模块文档](COMMERCIAL_COMMUNITY.md)。

| 层级 | 数量 | 实现方式 |
| --- | --- | --- |
| 商业经营 | 10 | 店铺、货架、库存、订单、交付、预约、评价、优惠券、收藏、经营统计；专用 SQL 事务及权限，线下结算 |
| 用户社区 | 4 | 可复用论坛、用户主页、产品展示、用户目录；共用实现但各应用数据独立 |
| 基础能力 | 10 | 身份、资料、校园、内容、搜索、聊天、通知、活动、小组、媒体的共享服务与页面 |
| 校园功能 | 50 | 领域字段、状态、隐私和视图各自定义，共用类型校验、SQL 存储、授权、搜索及 CRUD UI |
| 连接自动化 | 12 | 创建/更新/归档触发、状态/关键词/数值条件、字段映射、文本模板、通知、关联记录、审计、同名去重 |
| 展示组件 | 8 | 卡片、表格、看板、计数、状态汇总、搜索框、状态筛选器、内嵌记录区 |

校园功能按课程学习、校园生活、成长实践、社团协作、校园服务、个人效率筛选。权威字段与状态定义见 `packages/modules/src/business-catalog.ts`。

## 三种入口

- `/modules`：搜索名称、ID、别名和标签，按层级与领域筛选，切换网格/列表。
- `/modules/:moduleId`：简介、交互式界面预览、接口图、字段和端点、依赖和权限、安装到项目。详情预览明确标注示例，仅在页面本地运行；已部署应用使用真实 API。
- `/compose`：填写目标用户和业务流程，再拖入/点击添加模块，连接端口，编辑属性，保存项目，生成并打开真实应用。v2 要求至少 12 字产品描述，但无需 LLM 凭据即可执行已支持的声明式组合。

Agent 输入支持精确 `+失物招领`、`+聊天`、`+lost-found` 引用，包含自动补全、未知名称提示、持久任务引用及模块选择约束。应以空格或标点分隔引用。真实模型推理仍需模型凭据。

## 连接语义

| 连接 | 效果 |
| --- | --- |
| 依赖接口 | 展示并验证已有接口依赖；不会授予跨应用读取或任意执行权限 |
| 页面跳转 | 在来源模块呈现目标页面入口 |
| 内嵌记录 | 详情内读取/创建带父记录 ID 的子记录，最多 3 层 |
| 创建后通知 | 创建记录和插入操作者通知在同一事务中提交 |
| 自动化 | 事件流经条件、变换、受控动作；单次最多 160 步，不递归触发生成记录 |
| 展示数据 | 指定默认视图、显示统计、启用搜索/状态筛选、配置内嵌模块 |

画布声明模式下，搜索框和筛选器由相应连线启用；无画布的常规业务模块默认提供两者。数据库搜索接口始终进行权限校验。一个业务模块只允许一个画布入口，一个子模块只允许一个父入口。配置缺失、重复连接、循环、超过层数、私有到共享的数据关系会阻止保存。

v2 画布分为技术底座、产品业务、连接自动化和界面展示四个区域。新增模块自动补齐依赖节点及连线；缺少依赖、连接器没有业务输入或端口不兼容时标记错误，错误连线显示红色并阻止生成。订单/库存不支持接入普通记录修改连接器。旧 v1 图保留原契约，编辑后补齐依赖并保存可升级。

## 数据与安全

`migrations/runtime/002_module_records.sql` 在已有运行时数据库上增量迁移。应用数据库物理分离；每条记录包含模块、创建者、类型化 JSON 字段、状态和可选父记录。个人模块仅本人读取；共享模块允许应用内登录用户读取，但仅创建者可修改/归档。自动创建目标必须已安装，禁止把私有源复制到共享目标。单用户每模块累计 1000 条记录，列表最多返回 200 条；当前无分页 UI。

这套可视化流程只运行平台允许的声明式动作，不执行用户 Shell、任意 JavaScript 或外部 HTTP。现有单机 `local-trusted` 进程模式没有敌对租户隔离能力，不能作为公网任意代码托管。新增模块不声称具有官方教务对接、支付、实时车辆调度或审批引擎。

## 验证与复现

`npm run check` 覆盖 94 个清单、50 个记录模块的数据库 CRUD/搜索/权限/重启、12 个连接器、商业事务、社区、图校验及安全边界。`npm run e2e` 覆盖模块库、详情、引用、真实拖拽/连线/保存/部署、通知与嵌入记录、三个原有产品、商业社区和移动端。

`npm run deploy-visual` 使用已有本地开发账号创建一个独立画布示例并真实部署。配置写入 `.data/visual-showcase.json`，不会覆盖同名已存在项目的画布。已有运行实例需要刷新源码时使用 `npm run deploy-visual -- --redeploy`。

界面截图、业务模块逐项结果分别保存在 `artifacts/screenshots/` 和 `artifacts/business-module-results.json`。完整当前验证状态见 `TEST_REPORT.md`。
