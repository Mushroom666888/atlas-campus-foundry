# 使用说明

1. 打开 Studio，注册账号或使用本地交付账号登录。第一次注册的账号成为本机平台管理员。
2. 「创建产品」可选择 AI 开发或模块组装。模型未连接时 AI 需求仍会保存为 BLOCKED 任务；组装模式立即创建真实项目。
3. 在项目中编辑产品规格、查看模块版本、安装/卸载能力。依赖解析自动补齐所需模块；仍被依赖的模块不会实际移除。卸载保留业务数据。
4. 「项目文件」查看、编辑及保存真实工作区文件。构建/测试按钮调用隔离执行器。没有 Docker 时会明确报错，不在控制进程执行项目代码。
5. 「创建预览」启动应用进程。在部署列表打开应用后，需要应用自己的账户登录；平台账号不会自动暴露给应用。
6. Events 支持活动、报名、通知和地点；Marketplace 支持商品、图片、搜索、状态与私聊；Study Buddy 支持资料、主题、小组和聊天。
7. 所有示例数据都来自本地样例初始化，不代表真实学校活动、售卖或学生。学校归属为自主声明；邮箱验证不等同于学校官方认证。没有预置或伪造校园地图数据。
8. 聊天记录写入数据库，通过 SSE 接收新消息。站内通知可标为已读。
9. 部署页面支持日志、健康检查、停止、重启、回滚和移除实例。移除保留应用数据库。回滚恢复构件配置，不能把数据库回到旧时间点。
10. 模块发布目前接收容量/FIFO 候补策略契约。管理员查看契约和权限后发布，其他项目从 Registry 安装，不复制源项目。任意可执行模块的公共发布尚未开放。

截图见 `artifacts/screenshots/`。登录密码和 API Key 不应写入产品描述、项目源码或聊天日志。
